whosaid 使用教程

本地、私有的中文会议转写工具——把录音转成文字，并分清「谁在说」。以下是从下载到第一次转写的完整步骤，仅支持 Apple Silicon Mac（M 系列芯片）。

1下载安装

到 GitHub Release 页面下载最新的 whosaid_x.x.x_aarch64.dmg，双击打开，把 whosaid.app 拖进「应用程序」文件夹。无需另外安装任何东西——Python 运行时和 ffmpeg 都已打进包里。

2首次打开（去隔离）

whosaid 没有走 Apple 签名+公证，第一次双击会被 macOS 拦下、提示"已损坏"或"无法打开"——这是正常现象，不是真的损坏。

Release 里附了一个 首次打开.command 脚本，操作方式：

  • 下载 首次打开.command，和上一步一样先把 whosaid.app 拖进「应用程序」
  • 找到 首次打开.command，右键点击 → 打开（不要直接双击——脚本本身也没签名，直接双击同样会被拦，右键打开会弹一个"确定要打开吗"的确认框，点"打开"即可）
  • 会弹出一个终端窗口，跑完后提示"完成"，按任意键关闭
  • 之后就可以正常双击 whosaid.app 了

如果嫌麻烦，也可以直接打开「终端」，把下面这行命令里的路径换成实际拖入的位置后执行，效果等价：
xattr -dr com.apple.quarantine /Applications/whosaid.app

3注册 HuggingFace 访问令牌

whosaid 不随包分发说话人分离模型（避免帮你违反模型许可协议），第一次使用需要你自己注册 HuggingFace 账号、拿到访问令牌，并同意门控模型的使用条款：

  1. 注册 huggingface.co 账号（免费）
  2. 登录后到 Settings → Access Tokens，新建一个 Read 权限的 token，复制备用
  3. 依次打开下面两个模型页面，点 Agree and access repository 同意使用条款（说话人分离功能实际用到的两个门控模型）：
    • pyannote/segmentation-3.0
    • pyannote/speaker-diarization-community-1

4填令牌 + 下载模型

打开 whosaid，点侧栏「模型管理」：

  • 把第 3 步拿到的 token 粘进「HF 访问令牌」输入框，点保存
  • 国内网络访问 huggingface.co 慢/不通的话，「镜像地址」填 https://hf-mirror.com（留空则用官方地址）
  • 给「Belle 中文微调」（转写，免 token 也能下）和「pyannote 说话人分离 community-1」分别点「下载」

模型总共约 3G，下载中会一直转圈直到完成，请耐心等待。若提示令牌无效/未同意条款，回到第 3 步检查。

5开始使用

把录音文件（m4a/mp3/wav/aac/flac/mp4/mov/ogg）直接拖进 whosaid 窗口，等转写完成后即可看到分说话人的文字稿，支持改说话人名、导出 txt/srt。

开源组件与许可

本 app 内置了 FFmpeg（用于音频解码/切块）的静态构建，遵循其许可协议；对应源码可在 ffmpeg.org/download.html 获取。转写/说话人分离分别基于 mlx-whisper 与 pyannote.audio。
