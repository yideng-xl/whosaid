# whosaid v0.2.0

macOS Apple Silicon Beta 更新，适用于 macOS 13 及以上。

## 本次更新

- 直接录制电脑声音与麦克风。可连续录多段，保存后试听、重命名、删除，确认后手动转写；删除需要二次确认。
- 增强录音中断保存与恢复，休眠后按独立片段处理，避免把两场录音混为一段。休眠期间无法录音。
- 修复签名缺少麦克风音频输入权限的问题，增强音频设备切换后的麦克风恢复。
- 电脑声音、麦克风分别显示实时波形；新增默认关闭的圆角小悬浮窗，仅保留时间与两路波形，可拖动，双击返回应用。
- 支持维护多个具名词库，转写前按会议选择；通用词库默认选中，专用词库默认不选。
- 人名候选经人工确认后统一替换；调整三种稿件的导出按钮名称及顺序，导出内容保持不变。

## 安装与更新

1. 先停止并保存录音，等待排队、转写和分人任务结束，再退出 whosaid。
2. 下载 `whosaid_0.2.0_aarch64.dmg`，将应用拖入“应用程序”替换旧版。不要删除 Application Support 中的 whosaid 数据，历史任务、录音和词库保存在那里。
3. 首次运行按系统提示允许系统录音及麦克风权限。
4. 本包使用固定本地签名，尚无 Apple Developer ID 签名及公证。若系统拦截，请确认下载来源及 SHA-256；随附 `whosaid_0.2.0_first-open.zip` 中的脚本仅清除 whosaid 的下载隔离属性，确认信任后再执行。

## 已知边界

- 本次仅发布 Apple Silicon 安装包，不包含 Windows 更新。
- 模型不随安装包分发，首次使用需联网下载；转写在本机完成。
- 词库提供转写上下文，不保证人名和专用词一定正确；本版未切换到 FluidAudio 模型。
- 开始录音前若已明确拒绝麦克风权限，会提示先授权；录音过程中麦克风不可用时可能只保留电脑声音，请观察两路波形并试听。回声抑制不能保证消除所有回声。
- 合盖、休眠及设备故障可能造成缺失片段；恢复机制不能补回没有采集到的声音。重要会议仍建议保留独立录音备份。

附件的 SHA-256 校验值见 `SHA256SUMS.txt`。
