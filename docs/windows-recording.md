# Windows 录音同步

范围：Windows 10/11 x64。复用 macOS 的录音管理、词库、稿件和波形页面，转写继续使用 faster-whisper CPU 后端。

## 录音

- WASAPI 共享模式采集默认播放设备的系统声音和默认输入设备的麦克风。不主动独占音频设备；若其他应用独占设备，仍可能采集失败。
- 「全系统声音」指通过当前默认播放设备播放的各应用混音，不覆盖被单独路由到其他声卡的声音；受保护内容也可能无法录制。
- 两路音轨统一使用 QPC 时间轴，以 CAF 保存 48 kHz 单声道浮点 PCM。静音补齐时间，重复片段去重，异常退出后无需修复 WAV 长度字段。
- 耳机插拔、默认设备变化后重新连接；麦克风失败不停止电脑声音。电脑声源连续 10 秒无法恢复时结束采集、保留文件，提示恢复，不能假装仍正常录音。
- 熄屏保存当前段，亮屏后另开一段；整机休眠/合盖按结束处理，不自动继续。休眠期间无法采集。
- 停止后先试听，支持连续录制、倒序列表、重命名保存、二次确认删除，确认后才转写。
- 默认关闭圆角小悬浮窗，开启时显示时间和两路实时波形，可拖动，双击打开主窗口。

微软接口参考：[WASAPI 共享模式与 loopback](https://learn.microsoft.com/en-us/windows/win32/coreaudio/audclnt-streamflags-xxx-constants)、[系统电源通知](https://learn.microsoft.com/en-us/windows/win32/power/registering-for-power-events)。

## 词库与隐私

词库功能随代码同步，个人内容不随代码同步。新安装默认没有词库，用户在自己的 Windows 上维护。数据位于应用用户数据目录，不位于源码或安装资源目录。

Git 忽略个人词库、配置和录音；`check-private-data.py` 检查已跟踪文件和内核资源白名单。Windows 构建、macOS 发布及本地签名构建都运行该检查。测试只用虚构数据，不读取用户词条。

## 实机验收清单

CI 无真实麦克风和腾讯会议，编译或模拟音轨通过不等于录音验收。公开为稳定版前需要在 Windows 实机检查：

1. 默认无词库，新增通用/专用词库，重启后保留，转写选择正确。
2. 腾讯会议同时运行，双方说话，分别观察两路波形，录 2 分钟后试听完整。
3. 播放静音持续 90 秒再恢复，保存时长正确，后续声音没有丢失。
4. 插拔 USB/蓝牙耳机，检查重新连接、时间轴和设备不可用提示。
5. 熄屏/亮屏与合盖/唤醒分别验证，旧段可播放，新段符合上述规则。
6. 录音中异常结束进程后恢复音轨；磁盘写入失败必须报错且不删除原文件。
7. 连录、重命名、删除二次确认、试听后转写与三个导出按钮正常。
8. 悬浮窗默认关闭，圆角透明，无抢焦点，拖动与双击有效。

当前 macOS 安装应用无需更新，Windows 改动不替换本机应用或迁移个人词库。
